# Front Plas — prototipo estructural + skins

Astro 7 + Tailwind 4. Misma jerarquía de páginas; dos temperamentos visuales unidos por **educación en ingeniería**.

## Temas

| Switch | Temperatura | Color | Forma |
|--------|-------------|-------|-------|
| **PLaS** | Vibrante, abierta | Menta / turquesa | Bifurcaciones claras, tipografía Syne + Sora |
| **Felipe** | Recatada, cálida | Teal oscuro + beige / marrón | Misma geometría de árbol, Fraunces + Source Sans 3 |

Cambia con el switch del header o `?theme=plas` / `?theme=felipe`.

## Idea de forma

Educación = proceso **no lineal**. Secciones, CTAs e índices usan tronco + nodos + layout en horquilla (`growth-canvas`, `branch-node`, `fork-layout`, `leaf-panel`) en lugar de tarjetas típicas.

## Desarrollo

```bash
npm run dev
npm run build
```
